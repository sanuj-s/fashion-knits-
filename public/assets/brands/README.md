# Brand logo assets

These marks are locally stored for reliable loading and rendered in the colors present in each source file. Some source wordmarks are monochrome. Each brand retains ownership of its trademarks. Their presence in this gallery follows the company-provided list; client relationships and public-display permissions were not independently checked.

## Company-provided names

- `boss.svg` — [BOSS mark](https://commons.wikimedia.org/wiki/File:Hugo_Boss_logo_2021.svg).
- `timberland.svg` — [Timberland wordmark](https://commons.wikimedia.org/wiki/File:Timberland_wordmark.svg), sourced from timberland.com.
- `zadig-voltaire.svg` — [Zadig & Voltaire wordmark](https://commons.wikimedia.org/wiki/File:Logo_Zadig_et_Voltaire.svg), sourced from zadig-et-voltaire.com.
- `teddy-group.png` — [Teddy Group mark](https://www.teddy.it/en-us), from the official group website.
